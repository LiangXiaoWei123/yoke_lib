# I2C 寄存器表

| 地址 | 名称 | 访问 | 说明 |
| --- | --- | --- | --- |
| `0x00`-`0x01` | ID | R | 固定设备 ID：`0x4543` |
| `0x02` | KEY | R | bit7 为当前按键状态；bit3:0 为读取后清零的短按累计次数 |
| `0x03` | KEY_TIME | R | 最近一次按键时长，0.1 s/LSB |
| `0x04`-`0x05` | CNT | R | 16 位有符号编码器累计计数 |
| `0x06`-`0x07` | DIFF | R | 16 位有符号编码器增量；读取低字节后清零 |
| `0x08`-`0x0A` | LED1 RGB | R/W | LED1（远离连接器）的红、绿、蓝亮度 |
| `0x0B`-`0x0D` | LED2 RGB | R/W | LED2（靠近连接器）的红、绿、蓝亮度 |
| `0x0E` | CTRL1 | R/W | 写入 `0x5A` 进入测试模式；其他值仅保存 |
| `0x0F` | CTRL2 | R/W | I2C 地址低 3 位的非易失配置 |

寄存器支持连续读写。超出定义范围的读操作返回 `0xFF`；写操作返回 ACK，但不会修改数据。

## CTRL2

CTRL2 的有效格式为 `1 !A2 !A1 !A0 0 A2 A1 A0`。低 3 位为 7 位 I2C 地址的低 3 位，位 6:4 是其反码。组件会由 `yoke_ec11_configure_slave_address()` 自动生成该格式。
